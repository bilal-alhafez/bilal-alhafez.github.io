How to deploy to GitHub Pages

  1. Create repo e.g. bilal-studio on GitHub
  2. Upload index.html, admin.html, content.json, /assets folder if you have local media
  3. Repo Settings → Pages → Source: main branch / root
  4. For media: upload files to /assets and use relative path like assets/video.mp4 or paste external URL
  5. Use this admin.html locally or via Pages: edit, then Export content.json and replace file in repo
  6. Commit → site updates in ~1 min

Tip: For videos, keep under 15MB for fast Pages load. Use muted loop mp4. For DataURL uploads, they work but increase JSON size — prefer /assets path for production.
